# DonorSync

A modern healthcare-focused mobile application built using Flutter that helps connect organ donors, recipients, and emergency requests through a clean and accessible digital platform.

This project was developed to simplify the organ donation process, spread awareness, and provide a centralized system for managing donor information and emergency organ requests.

---

## Features

- Donor Registration System
- Emergency Organ Request Module
- Organ-Based Filtering & Search
- Call Integration for Quick Contact
- Modern Flutter UI Design
- Clean and Responsive Layout
- Healthcare Awareness Information Pages

## Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/Atharvakumkar/Organ-Donation-App.git
```

### Navigate to Project Folder

```bash
cd Organ-Donation-App
```

### Install Dependencies

```bash
flutter pub get
```

### Run the App

```bash
flutter run
```
